# ADR-001: Application toolchains

Status: Accepted
Date: 2026-09-25
Owner: Project owner / developer
Requirements/tasks: REQ-08, REQ-09, REQ-13 / TASK-001

## Context
The assignment requires Next.js/React/TypeScript and Spring Boot 4.x/Kotlin/Maven. The current host has Java 25 and Docker, but no global Node.js or Maven.

## Decision
- Frontend: Node.js 24.15.0, npm lockfile, Next.js 16.3.6, React 19.3.0, TypeScript 5.9.3, ESLint 9.39.5, Vitest 5.0.2 and React Testing Library 16.3.3. TypeScript 7 and ESLint 10 were rejected because the installed lint/test dependency graph did not declare compatible peer ranges.
- Backend: Java 21 target, Spring Boot 4.1.1, Kotlin 2.3.21 and Maven Wrapper generated by Spring Initializr.
- Local services: PostgreSQL 17 and Redis 8 through Docker Compose.
- Developers may use pinned host tools or Docker. CI/release automation remains outside TASK-001.

## Consequences and verification
Java 21 is the portable backend baseline while the installed Java 25 can execute it. Node and Maven do not need global installation. Exact versions are kept in manifests, lockfiles, wrapper properties and container images. Build/test commands and evidence must demonstrate compatibility before TASK-001 is complete.
