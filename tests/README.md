# Cross-system tests

- `contract/`: API schema/consumer compatibility
- `e2e/`: user journeys ระหว่าง frontend และ backend
- `performance/`: k6 workloads และผลการรัน

Unit/component และ integration tests อยู่กับ frontend/backend ดู [test strategy](../docs/quality/test-strategy.md); k6 workload และผลอยู่ใน `performance/`
